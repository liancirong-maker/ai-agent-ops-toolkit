## 三、每个核心 Skill 沉淀的关键规则

### 开户助手
- 生态双挂：广告主名下**不能**已有有效代理子账号，并且必须已开通投放账户
- 一户多开：广告主名下**必须**已有至少一个代理子账号，且只能走走账端口
- 名下没有任何代理子账号时，应走首次开户，不能用一户多开
- 邮箱被占用是最常见的阻塞原因，需要换邮箱后重新提报
- 用户输入的邮箱有拼写错误时，不自动修正，先向用户确认

### 防骚扰开白
- 审核核心口径：同行导流、虚假留咨、灰产
- 证据分级：**强** = 证据闭环完整；**中** = 对方有实际发言但性质不典型；**弱** = 对方没有实际发言
- 同一账号、同一计划的多张截图合并为一单，避免重复提报
- 自动校验字段格式：投放账号 ID 为纯数字，企业号 ID 为 24 位十六进制；字段错位时拦截
- 计划 ID 量级明显异常时提示人工确认

### 挂接查询 + 分配判定
见 [allocation-rules.md](allocation-rules.md)。

### 分配结果查询
- 结果分为：成功 / 已有服务商 / 余额不足 / 投放方式失败 / 服务商重复 / 目标服务商不存在 / 系统错误 / 未处理
- 终态判断：失败、未进表、已有服务商视为终态；备注为空才是「未处理」
- 查询优先用 UID，按名称查容易漏命中
